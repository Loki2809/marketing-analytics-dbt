## Goal
A portfolio project that proves I can do analytics engineering on the modern data stack:
dbt models in layers, tests, snapshots, incremental models, CI/CD, documentation.
Target roles: Analytics Engineer / Data Engineer (US).

## Business story
A fictional online store runs ads on Google, Meta, and email.
Marketing leadership asks: Which channels bring customers? What does each customer cost (CAC)?
What return do we get on ad spend (ROAS)? Where do people drop out of the funnel?

## Stack
- Warehouse: Snowflake (30-day free trial). Use an X-SMALL warehouse with auto-suspend at 60 seconds to save credits.
- Transformation: dbt Core (`dbt-snowflake`), run locally.
- Data generation: Python (pandas + Faker) creates realistic synthetic CSVs.
- Version control: GitHub (public repo).
- CI: GitHub Actions runs `dbt build` on every pull request.
- Dashboard (final step): Power BI connected to Snowflake marts.

## Raw data (generated by Python, loaded into Snowflake schema RAW)
- `customers`: customer_id, email, signup_date, country, updated_at
- `web_sessions`: session_id, customer_id (nullable), session_start, utm_source, utm_medium, utm_campaign, device
- `events`: event_id, session_id, event_name (page_view, add_to_cart, begin_checkout, purchase), event_timestamp
- `orders`: order_id, customer_id, order_date, revenue, status
- `ad_spend`: date, channel, campaign, impressions, clicks, spend
- `campaigns`: campaign_id, campaign_name, channel, start_date, end_date

Include messy data on purpose (duplicates, null UTMs, mixed-case channel names, test orders)
so the staging layer has real cleaning work.

## dbt layers
- `staging/` — one model per raw table. Rename, cast types, clean. No joins. Prefix `stg_`.
- `intermediate/` — joins and business logic (sessionized funnel, touchpoints per customer). Prefix `int_`.
- `marts/` — final tables for reporting:
  - `dim_customers`, `dim_campaigns`, `dim_date`
  - `fct_sessions`, `fct_orders`, `fct_ad_spend_daily`
  - `fct_attribution` (first-touch and last-touch)
  - `mart_marketing_kpis` (CAC, ROAS, conversion rate by channel and month)
